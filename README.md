# Stickhold – öffentliche Releases

Hier werden die offiziellen stabilen Spielversionen von Stickhold veröffentlicht und zum Herunterladen bereitgestellt.

## Spiel herunterladen

**[Neueste stabile Version herunterladen](https://github.com/vollictor/Stickhold-Releases/releases/latest)**

[Alle veröffentlichten Versionen](https://github.com/vollictor/Stickhold-Releases/releases)

Öffne die gewünschte Version und lade unter **Assets** das passende Spielpaket herunter. Die von GitHub automatisch erzeugten „Source code“-Archive enthalten nur den Inhalt dieses Release-Repositories, nicht das spielbare Spiel.

**Aktueller Stand:** Veröffentlicht ist die Testversion vom 27.09.2026 für Windows (64 Bit). Sie ist ein Entwicklungsstand zum Testen, kein fertiges Spiel; die Hinweise zum Starten stehen beim Release.

## Zweck dieses Repositories

Dieses öffentliche Repository dient der Verteilung fertiger, stabiler Spielversionen und ihrer Versionshinweise. Die Entwicklungsumgebung und der Spielquellcode bleiben im separaten privaten Repository.

## Eine stabile Version veröffentlichen

1. Im privaten Entwicklungsrepository einen stabilen Build erstellen und prüfen.
2. Hier unter **Releases → Draft a new release** eine Version mit einem Tag wie `v1.0.0` anlegen.
3. Die fertigen Spielpakete als **Assets** hochladen und die Änderungen in den Versionshinweisen beschreiben.
4. Das Release als stabile Version veröffentlichen und als **Latest** kennzeichnen.
5. Den Download prüfen. Der feste Link oben führt danach zur neuesten als „Latest“ markierten stabilen Version.
